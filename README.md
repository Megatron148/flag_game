# 🌍 Flag Quiz Game — Powered by VEXOR AI

An adaptive, AI-driven flag identification game built with Python and Streamlit. The game features a dynamic AI villain (VEXOR), real-time performance analytics, and an intelligent difficulty engine that learns your weaknesses and exploits them.

---

## 🎮 What It Does

Players are shown flags from 250+ countries and territories and must identify them by name. What makes this different from a standard quiz app is the adaptive intelligence layer underneath:

- **VEXOR** — an AI-powered villain character (GPT-OSS 120B via Groq API) that generates unique, personalized commentary throughout the game based on your performance
- **Adaptive Difficulty Engine** — tracks your accuracy across 8 geographic regions in real time and deliberately targets your weakest region as the game progresses
- **Progressive Hint System** — combines letter count and first-letter hints with three AI-generated clues that become progressively more specific
- **Regional Performance Analytics** — full post-game breakdown showing accuracy across Europe, Americas, Asia, Africa, Middle East, Oceania, Territories, and Lookalikes
- **AI Fun Facts** — on every correct answer, the AI generates a surprising and obscure fact about that country
- **Post-Game Roast** — VEXOR delivers a personalized performance roast based on exactly how you played, targeting your weakest region

---

## 🧠 How the Adaptive Difficulty Works

The game is structured in 5 phases:

| **Flag #** | **Phase**    | **Strategy**                                                        |
| ---------- | ------------ | ------------------------------------------------------------------- |
| 1–5        | Warm Up      | Famous, well-known flags only                                       |
| 6–15       | Surveillance | All regions, no territories or lookalikes — VEXOR is watching       |
| 16–20      | Targeting    | Deliberately targets your weakest region                            |
| 21–25      | Exploitation | Combines your weak region with lookalike flags                      |
| 26+        | All Out      | Weak region + lookalikes + obscure territories — maximum difficulty |

## 📦 Installation

### Prerequisites

- Python 3.8+
- A Groq API key (free at [console.groq.com](https://console.groq.com/))

### Setup

```bash
# Clone the repository
git clone https://github.com/Megatron148/flag_game.git
cd flag_game

# Install dependencies
pip install streamlit pillow groq python-dotenv

# Create environment file
```

## 🌟 Key Features

### VEXOR — The AI Villain

VEXOR is not a static character. Every message is dynamically generated by GPT-OSS 120B based on:

- Which flag number you're on
- Your current weakest region
- Whether this is your first time seeing VEXOR
- How far you've survived into the game

This creates a genuinely unique experience every playthrough.

### AI-Generated Hints

The game uses Groq's API to generate three dynamic clues for each flag:

- **Hint 1:** A broad geographical clue
- **Hint 2:** A clue about the country's culture, history, or geography
- **Hint 3:** A more specific clue to help identify the country

Hints are generated on demand using the correct country as context, without directly revealing its name or capital.

### Region Tracking System

The game silently tracks your performance across 8 regions:

- 🌍 Europe | 🌎 Americas | 🌏 Asia | 🌍 Africa
- 🕌 Middle East | 🌊 Oceania | 🏴 Territories | 👯 Lookalikes

Each wrong answer is counted once per flag per region — preventing score inflation from repeated guesses on the same flag.

### Lookalike Challenge

A special category of flags that are visually similar to other countries (e.g., Chad/Romania, Indonesia/Monaco) — deployed strategically in later rounds to test expert-level knowledge.
